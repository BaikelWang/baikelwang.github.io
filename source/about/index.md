# 你好，与你握手。

我是北海，南京邮电大学材料与工程学院电子信息专业硕士研究生，研究与实践主要集中在**材料智能、AI for Science 与 AI 工程**。

我喜欢站在科学问题与软件系统的交界处工作：一方面探索晶体结构、图神经网络、生成模型和 PXRD 等问题；另一方面尝试把模型训练、评测、推理、数据处理与可视化串联起来，做成真正能够运行和使用的工具。比起只让模型“得到一个结果”，我更关心结果是否可信、流程是否可复现，以及系统能否被稳定地交付和维护。

目前，我主要关注三个方向：

- **AI for Science**：材料性质预测、晶体生成、科学机器学习与可解释性；
- **AI 工程**：模型训练与评测、推理服务、科研软件和自动化工作流；
- **人与 AI 协作**：LLM、Agent、Vibe Coding，以及让知识在文件系统中持续积累的方法。

这个网站记录我的学习、研究、工程实践与个人思考。这里既有对技术原理的梳理，也有真实项目中的问题、失败和复盘。我希望它不只是一个结果展示页，而是一份能够长期生长、经得起回看的个人工作记录。

很高兴你来到这里。欢迎通过 GitHub 与我交流。
